# CancerCare — Step 5: Collaboration diagram

The three circles in the collaboration section now represent people's voices, health expertise, and community. Their overlap points to the shared goal: clearer care information. These are planned contributors to the project, not a claim that formal partnerships already exist.

The labels and outcome line are available in English and Kiswahili. They are real HTML text so they can resize, translate, and be read in order by assistive technology. The existing section description supplies more context.

The diagram was checked at desktop and phone widths in both languages. The TypeScript production build passed.
